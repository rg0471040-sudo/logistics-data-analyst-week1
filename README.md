# Logistics Data Analyst Internship – Week 1

## Project
Strategic Planning and Data Exploration in Logistics

## Scenario
E-commerce delivery performance and inventory allocation.

## Purpose
This repository supports the Week 1 strategic-planning report. It contains an illustrative Python workflow for:
- data-quality checks
- date parsing
- delivery-time calculation
- late-delivery identification
- KPI calculation

The code is intentionally written as a starting template and does not claim fabricated business results.

## Files
- `logistics_week1_analysis.py` – Python analysis template
- `README.md` – project documentation
- `requirements.txt` – Python packages

## Expected input
The script expects a CSV named `logistics_orders.csv` with these columns:

`order_date, dispatch_date, promised_date, delivery_date`

Additional columns such as `distance`, `transport_mode`, `warehouse`, `order_value`, and `quantity` can be added for deeper analysis.
